# fishybot
**fishybot** is a Discord bot and server daemon running on Socii Cybernetici's tilde-style server, "fishy.best". It listens for requests to dedicated endpoints at https://fishy.best/ to help automate user signup by letting admins interact with the server over Discord.

### Build instructions
(Why would a third party build this? Who knows?)
```
$ git clone https://github.com/Socii-Cybernetici/fishybot.git
$ make
```
